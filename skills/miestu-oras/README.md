# miestu-oras

Įgūdis, kuris tikrina Gismeteo.lt ir pateikia dabartinę temperatūrą bei oro sąlygas Vilniuje, Kaune, Klaipėdoje, Šiauliuose ir Panevėžyje.

## Turinys

- `SKILL.md` — įgūdžio instrukcijos
- `agents/openai.yaml` — agento sąsajos metaduomenys
- `evals/evals.json` — trys pradiniai patikros scenarijai

## Naudojimas

Įdėk `miestu-oras/` katalogą į savo skills katalogą, išlaikydamas šią struktūrą.
